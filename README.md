Restaurant Analytics Dashboard | Power BI

Project Overview

The Restaurant Analytics Dashboard is an interactive data visualization project developed using Microsoft Power BI. The dashboard provides insights into   restaurant performance, customer ratings, pricing, online delivery services, table booking facilities and geographical distribution.

The main objective of this project is to explore restaurant data, identify business patterns and present meaningful insights through interactive visualizations.

Key Performance Indicators (KPIs)

- Total Restaurants
- Average Restaurant Rating
- Total Votes
- Table Booking Restaurants
- Online Delivery Percentage

Dashboard Features

- Restaurant Distribution: Analyze the number of restaurants across different cities.
- Rating Analysis: Understand restaurant ratings and rating categories.
- Price Range Analysis: Compare average restaurant ratings across different price ranges.
- Online Delivery Analysis: Examine restaurant availability based on online delivery services.
- Cost vs. Rating Analysis: Explore the relationship between average cost and restaurant ratings.
- Geographical Analysis: Visualize restaurant locations using an interactive map.
- Interactive Filters: Filter data by city, cuisine, country, price range, rating, online delivery and table booking.

Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning and Transformation
- Data Visualization

Project Objectives

- Analyze restaurant performance and distribution.
- Identify rating patterns across different price categories.
- Understand restaurant service availability.
- Explore geographical restaurant distribution.
- Convert raw data into meaningful business insights.
